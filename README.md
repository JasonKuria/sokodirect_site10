SokoDirect is a full-stack agricultural marketplace developed to connect small-scale farmers directly with consumers, retailers, and other buyers, helping address challenges such as limited market access, post-harvest losses, dependence on intermediaries, and high consumer prices. The platform allows farmers to create profiles and list agricultural products while buyers can browse and search products, view categories, communicate with sellers, place orders, review products, and progress through a shopping-cart and checkout workflow. The system uses Python, Django, PostgreSQL, Django ORM, HTML, CSS, JavaScript and Django Templates, with features including user authentication, profiles, product CRUD, hierarchical product categories, messaging, reviews, search, pagination, email/password-reset functionality, orders and checkout. The architecture is also designed for expansion through Django REST Framework APIs, mobile applications and digital-payment integration such as M-Pesa, making SokoDirect a scalable foundation for a Kenyan agricultural e-commerce ecosystem.
